## 📝 Notes & Astuces

### 📅 Saison — pourquoi mai ?
- **Mi-mai → début juin** : 🌸 après Golden Week (fin avril), avant les pluies de mi-juin. Températures 18-25 °C, ciel souvent dégagé.
- Les **montagnes (Fuji, Kurama)** sont les plus belles en mai — verdure fraîche.

### ⚠️ Corrections apportées au document source
- « Rando Mont Hushiwari » → **montagne à confirmer** : le plus probable est le **Mont Mitsutoge** (randonnée classique vue Fuji depuis Kawaguchiko) — l'ascension du **Fuji officiel est fermée en mai** (saison juillet-août uniquement). Vérifier le nom exact.
- « Kira kamakura » → **Kita-Kamakura** (l'arrêt AVANT Kamakura — on descend à pied par les temples).
- « Kinkaku-ju » → **Kinkaku-ji** (le Pavillon d'Or).
- J6 : randonnée le matin + trajet Kawaguchiko → Kyoto l'après-midi = journée dense mais faisable (rando courte + bus 14h → arrivée Kyoto ~19h).

### 🚶 Rythme & logistique
- **J4 et J16 (Nikko)** : garder les 2 créneaux possibles — un pour le beau temps, l'autre en réserve (météo).
- **Kyoto** : se lever tôt pour Fushimi Inari (7h) et Arashiyama (avant 8h) — éviter la foule.
- **Dimanche** : USJ + Nintendo World souvent bondés — si possible, choisir un **jour de semaine** pour J12.
- **Bagages** : prévoir un sac léger pour Kawaguchiko (J5-J6) — pas de porteur de valises sur la rando.
- **Japon cash-lite** : carte bancaire + Suica suffisent (mais quelques milliers de yens en liquide pour les petits temples/kiosques).

### 💡 Bonus si le budget le permet
- **Kobe** (journée depuis Osaka) : bœuf de Kobe + vue port — uniquement si grosse motivation (J13 optionnel).
- **Nishiki Market** (Kyoto) : déjeuner rapide avant le départ vers Osaka le J10.
