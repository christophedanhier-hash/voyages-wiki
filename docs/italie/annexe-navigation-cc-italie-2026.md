## 2. Règles de décision

Pour chaque tronçon, trois variantes seront étudiées :

1. **Rapide / autoroute** — temps minimal, coût de péage potentiellement élevé.
2. **Mixte** — autoroute sur les portions utiles, évitement des péages lorsque le détour reste raisonnable.
3. **Sans péage** — économie maximale, mais davantage de kilomètres, traversées de villages et fatigue.

### Règles spécifiques au camping-car

- Toujours conserver le profil **8 m / 2,50 m / 2,80 m** dans le TomTom.
- Refuser les routes de montagne secondaires non nécessaires.
- Refuser les routes étroites, les demi-tours et les accès non vérifiés.
- Vérifier les tunnels, les limitations de hauteur et les accès finaux aux campings.
- Google Maps ne sert pas de GPS principal pour ce véhicule.
- Chaque tronçon sera validé séparément avant mise à jour du roadbook principal.

# 4. Tronçon 2 — Colmar → Lac Majeur / Maccagno

## Parcours de travail retenu : autoroute suisse

### ⚠️ Anomalie détectée dans le calcul direct

Le calcul automatique direct vers Maccagno propose une arrivée par :

- Via Indemini ;
- Via alla Forcora ;
- routes de montagne secondaires.

Cette variante n’est **pas retenue** pour un camping-car de 8 m.

### Itinéraire sécurisé à programmer avec des points de passage

**Colmar → Bâle → Lucerne → tunnel du Gothard → Bellinzona → Locarno → Luino → Maccagno**

Le waypoint **Luino** est important afin d’éviter une proposition automatique par la Forcora.

### Distances par segments

| Segment | Distance | Temps de conduite estimé |
|:---|---:|---:|
| Colmar → Locarno | 320 km | 3h59 |
| Locarno → Luino | 37 km | 44 min |
| Luino → Maccagno | 19 km | 27 min |
| **Total sécurisé** | **376 km** | **5h10** |

### Temps total avec pauses

| Élément | Durée |
|:---|---:|
| Conduite | 5h10 |
| Pause repas | 30 min |
| Pause courte | 15 min |
| **Total de travail** | **5h55** |

### Horaires selon le départ de Colmar

| Départ de Colmar | Arrivée estimée à Maccagno |
|:---:|:---:|
| **07h30** | Vers **13h25** |
| **08h00** | Vers **13h55** |
| **08h30** | Vers **14h25** |

Le check-in du camping étant prévu à partir de 16h00, une arrivée vers 14h00 laisse une marge pour un arrêt prolongé ou une attente avant l’installation.

### Carburant

- Après Sombreffe → Colmar : environ **18,5 L restants**.
- Colmar → Maccagno par Luino : environ **37,6 L consommés**.
- **Plein diesel à Colmar fortement recommandé avant le départ.**

### Accès final au camping

La confirmation du camping précise :

- hauteur maximale standard : 2,60 m ;
- le camping-car fait 2,80 m ;
- utiliser **Via Giuseppe Verdi** pour l’accès des véhicules de plus de 2,60 m ;
- ne pas accepter une variante TomTom par Via Indemini ou Via alla Forcora.

### Vignette suisse

- Vignette électronique suisse : **reçue et commandée**.
- Reçue par email le **10/08/2026**.
- Valable pour le trajet aller et le retour par la Suisse.

### Décision

**Statut : À valider par Christophe.**

La proposition recommandée est l’autoroute suisse, avec passage imposé par **Locarno et Luino**, puis accès final par **Via Giuseppe Verdi**.
